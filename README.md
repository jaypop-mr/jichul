# 지출의 신

지출 제목과 금액을 한 줄로 치면 지출품의서를 완성해 주는 도구입니다.

**https://jaypop-mr.github.io/jichul/**

## 쓰는 법

1. 처음 열면 뜨는 창에 **쓰던 지출품의서를 통째로 붙여넣고** 「분석해서 채우기」
   → 예산액·지출대상·결제계좌·예산과목이 자동으로 채워집니다.
2. 그다음부터는 한 줄만 칩니다.

```
정비 비용 30000
유류비 5만원
물건 구입 128,000원
```

3. **제목까지 복사** → 한글(HWP)에 붙여넣기

## 자동으로 되는 것

- 금액 한글 변환 — `30,000(금삼만원)`
- **기지출액 누적** — 복사하는 순간 이번 건이 더해집니다
- **지출잔액** 자동 계산, 예산 초과 시 경고
- 제목·본문·붙임의 지출 제목 자리를 알아서 치환 (조사 을/를 포함)

## 참고

- 예산 설정과 집행 내역은 **그 브라우저에만** 저장됩니다. 서버로 가지 않습니다.
- 여러 예산과목을 쓰면 상단에서 예산을 추가해 전환할 수 있습니다.
- 예산 설정은 「예산 목록 → 내보내기」로 동료에게 코드로 전달할 수 있습니다.
